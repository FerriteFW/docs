# Ferrite manual

The user manual for Ferrite, the firmware for the Radtel RT-950 Pro, as published at https://ferritefw.dev.

- `manual.md`: the index; `manual/`: one file per chapter; `img/`: the screens it shows.
- Build: `python3 tools/mkmanual.py` (needs `markdown`) -> `manual.html`.
