# Contributing

This is Ferrite's public manual. It's generated from the project's sources at each release, so a change made here directly would be overwritten.

## Issues

Something wrong, unclear or missing in the manual: open an [issue](https://github.com/FerriteFW/docs/issues), with the chapter and rule number (such as SQL-7) if there is one.

## Pull requests

Pull requests are welcome too, with the contributor agreement: we apply the change in the manual's source and credit you, and it appears here with the next release.

- **The agreement:** read [CLA.md](CLA.md) and tick its box in the pull request template. Once, on your first pull request: it then covers everything you send to the project: Ferrite, Ferrite Console, the manual and the website. You keep your copyright. Your name goes in [CLA-SIGNED.md](CLA-SIGNED.md).
- **The manual is the spec:** it says what Ferrite does. A change to how Ferrite behaves belongs in an issue on [ferrite](https://github.com/FerriteFW/ferrite/issues) first.
